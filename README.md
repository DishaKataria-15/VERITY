# VERITY

## An Evidence-First AI Answer Engine

VERITY is an AI system designed to provide answers together with
claim-level evidence, source analysis, conflict detection, and
uncertainty estimation.

Instead of simply generating an answer, VERITY evaluates the evidence
supporting each factual claim.

## Core Pipeline

Question
→ Query Analysis
→ Web Retrieval
→ Evidence Extraction
→ Answer Generation
→ Claim Extraction
→ Claim Verification
→ Conflict Detection
→ Source Evaluation
→ Reliability Assessment

## Planned Features

- Multi-source web retrieval
- Claim-level evidence
- Source quality assessment
- Conflict detection
- Temporal reasoning
- Reliability scoring
- Evidence transparency
- Interactive evidence graph
